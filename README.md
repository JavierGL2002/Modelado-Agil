# Introducción al agilismo

Sitio estático en español que presenta los valores del Manifiesto Ágil y un ciclo simple de trabajo iterativo.

## Archivos

- `index.html`: contenido del sitio.
- `styles.css`: diseño adaptable a escritorio y móvil.

No necesita dependencias ni comandos de compilación. El contenido sobre los cuatro valores se basa en el [Manifiesto Ágil](https://agilemanifesto.org/iso/es/manifesto.html).
